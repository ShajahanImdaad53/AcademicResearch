# Ethics & Data Protection Protocol

## 1. Principles
This project adheres to ethical research principles, prioritizing participant privacy, data minimization, and informed consent.

## 2. Data Collection and Storage
- **Anonymization:** All participant data will be pseudonymous. No student IDs, names, or contact emails will be stored in the training dataset. Participants will be assigned a random generic ID (e.g., P001).
- **Data Minimization:** We only collect data necessary for the machine learning model and scheduling constraints (e.g., subject difficulty, availability). We do not collect demographic or sensitive personal information.
- **Storage:** All raw data will be stored securely on password-protected, encrypted local storage, not in public GitHub repositories.

## 3. Voluntary Participation and Withdrawal
- Participation is entirely voluntary.
- Participants may withdraw at any time during the study without penalty.
- Instructions for requesting data deletion will be provided in the Participant Information sheet.

## 4. Model Transparency and Bias
- The schedule generation will explain its reasoning (e.g., "Subject X prioritized because the exam is in 3 days").
- We acknowledge that self-reported data may contain bias, which will be discussed in the final report limitations.
