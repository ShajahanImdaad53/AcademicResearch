# Data Collection Protocol

## 1. Overview
This protocol outlines how data will be collected, stored, and prepared for the Machine Learning phase of the AI-Based Personalized Study Schedule Recommendation System.

## 2. Collection Method
- Data will be collected via an online survey platform (e.g., Google Forms or Qualtrics).
- Only students who have signed the `PARTICIPANT_INFORMATION_AND_CONSENT_DRAFT` will be permitted to submit data.
- For prototype development prior to ethics approval, a synthetic dataset reflecting this exact schema will be generated by a Python script, clearly labelled as `synthetic_data.csv`.

## 3. Data Ingestion
- Exported survey results (CSV) will be downloaded to a secure local machine.
- Raw CSVs will be placed in `data/raw/`.
- **CRITICAL:** `data/raw/` must be added to `.gitignore` to prevent accidental uploads of unanonymized or raw survey data.

## 4. Preprocessing Steps
The script `src/data/preprocess.py` will:
1. Strip any identifiable metadata accidentally captured by the survey platform (e.g., timestamps, IP addresses).
2. Assign pseudonymous `Participant_ID`s.
3. Validate data types against the `DATA_DICTIONARY.md`.
4. Output the cleaned dataset to `data/processed/clean_data.csv`.

## 5. Storage and Retention
- Data will be retained only for the duration of the research project.
- Upon project completion and final grading, raw data files will be permanently deleted unless university policy mandates a specific retention period for reproducibility.
